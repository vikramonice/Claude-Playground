# Dr. Vikram Goel - Portfolio Website

A professional portfolio website for Dr. Vikram Goel, Antarctic Glaciologist and Scientist at the National Centre for Polar & Ocean Research.

## About

This website showcases Dr. Vikram Goel's research, publications, awards, and contributions to Antarctic glaciology and polar science.

## Features

- **Responsive Design**: Optimized for all devices (desktop, tablet, mobile)
- **Modern UI**: Clean, professional design with smooth animations
- **Sections Include**:
  - About & Research Interests
  - Education Timeline
  - Research Experience
  - Publications (Peer-reviewed papers)
  - Awards & Recognition
  - Leadership & Activities
  - Contact Information

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Google Fonts (Inter)

## GitHub Pages Setup

This site is configured to be hosted on GitHub Pages. To deploy:

1. Go to repository Settings
2. Navigate to Pages section
3. Select the branch: `claude/vikram-goel-portfolio-site-011CUrDTWwLSyZ1k4eSYgj2F`
4. Set folder to `/root` or `/docs` depending on your preference
5. Click Save

The site will be available at: `https://[username].github.io/Claude-Playground/`

## Local Development

To run locally:

1. Clone the repository
2. Open `index.html` in your browser
3. Or use a local server:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`

# Dr. Vikram Goel - Portfolio Website

A professional portfolio website for Dr. Vikram Goel, Antarctic Glaciologist and Scientist at the National Centre for Polar & Ocean Research.

## About

This website showcases Dr. Vikram Goel's research, publications, awards, and contributions to Antarctic glaciology and polar science.

## Features

- **Responsive Design**: Optimized for all devices (desktop, tablet, mobile)
- **Minimalist Academic Style**: Clean, professional design inspired by academic portfolios
- **Full-Screen Hamburger Navigation**: Modern menu overlay with smooth transitions
- **Photo Gallery with Lightbox**: Interactive image gallery with full-screen viewer
- **Sections Include**:
  - Hero banner with full-width glacier imagery
  - About & Research Interests (with profile photo)
  - Projects & Field Expeditions
  - Publications organized by year
  - Presentations & Conferences
  - Photo Gallery (Antarctic field work)
  - Awards & Recognition
  - Leadership & Service
  - Contact Information

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript (Lightbox functionality)
- Google Fonts (Raleway, Lato)

## Adding Photos to the Website

The website includes a photo gallery section and space for hero images and a profile photo. To add your own images:

1. **Read the Image Guide**: See [IMAGE_GUIDE.md](IMAGE_GUIDE.md) for complete instructions
2. **Add images to folders**:
   - `images/hero/` - Full-width banner images
   - `images/profile/` - Your profile photo (circular display)
   - `images/gallery/` - Gallery photos for the Photos section
3. **Recommended specs**:
   - Hero images: 1920x1080px (JPG)
   - Profile photo: 600x600px square (JPG)
   - Gallery photos: 1200x800px (JPG, optimized)

The gallery includes:
- Responsive grid layout (3/2/1 columns based on screen size)
- Interactive lightbox viewer (click any photo)
- Keyboard navigation (arrow keys, ESC)
- Image lazy loading for performance

## Local Development

To run locally:

1. Clone the repository
2. Open `index.html` in your browser
3. Or use a local server:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`

**Note:** Some features work best with a local server (image loading, etc.)

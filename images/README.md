# Images Folder

This folder contains all images for the website.

## Directory Structure

- **hero/** - Full-width header/banner images for sections
- **profile/** - Profile photo (circular display)
- **gallery/** - Photo gallery images for the Photos section

## How to Add Images

See the [IMAGE_GUIDE.md](../IMAGE_GUIDE.md) file in the root directory for detailed instructions on adding and managing images.

## Quick Start

1. Add your images to the appropriate folder
2. Update the `src` attributes in `index.html` to match your image filenames
3. Commit and push your changes

## Image Specifications

### Hero Images
- **Size:** 1920x1080px (or similar widescreen)
- **Format:** JPG or PNG
- **Files:**
  - `main-hero.jpg` - Homepage hero
  - `projects-hero.jpg` - Projects section
  - `publications-hero.jpg` - Publications section
  - `photos-hero.jpg` - Photos section

### Profile Photo
- **Size:** 600x600px (square)
- **Format:** JPG or PNG
- **File:** `profile.jpg`

### Gallery Photos
- **Size:** 1200x800px recommended
- **Format:** JPG (preferred) or PNG
- **Naming:** Use descriptive names (e.g., `expedition-1.jpg`, `ice-core-drilling.jpg`)

## Placeholder Images

Currently, the website uses gradient backgrounds as placeholders. Replace these with your actual photos by adding images with the correct filenames to these folders.
